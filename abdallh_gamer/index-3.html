راهنمای استفاده

۱. از بخش HTML کد صفحه را وارد کن.

۲. در تب CSS ظاهر سایت را تغییر بده.

۳. در تب JavaScript قابلیت‌های تعاملی اضافه کن.

۴. روی «اجرای پیش‌نمایش» بزن.

۵. برای نگهداری پروژه در همین مرورگر، آن را ذخیره کن؛ برای دریافت فایل نهایی از «دانلود فایل HTML» استفاده کن.
